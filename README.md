# GoDev — Visiting Card Website (Vue)

Static, advertisement-focused “digital visiting card” site built with **Vue 3 + Vite**. No backend.

## Run locally

```bash
npm install
npm run dev
```

## Lint

```bash
npm run lint
```

## Build

```bash
npm run build
npm run preview
```

## Update the content

Edit placeholder text/links in `src/App.vue` (name, email, phone, socials, services, work tiles).
